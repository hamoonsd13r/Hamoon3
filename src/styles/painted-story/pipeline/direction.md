# <شماره> · «<عنوان>» — برگه‌ی کارگردانی (Painted Story)

- **قالب:** افقی 1920×1080 (یوتیوب، قسمت‌های ۱ تا ۳ دقیقه‌ای یا کامل) / عمودی 1080×1920 (ریلز و شورتس، ۴۵ تا ۹۰ ثانیه) · 30fps
- **نگاه:** doc (آدمک‌های تخت، شب آبی، اکسنت نارنجی) / tale (پلیت نقاشی‌وار، کات‌اوت، مریمی + جنگلی + بلاش، اکسنت گوجه‌ای)
- **پالت:** توکن‌های `lib/theme.ts` (`NIGHT_DOC` یا `FOREST_WARD`). رنگ برند خودت فقط در `accent` می‌نشیند.

- پایان: ضربه‌ی آخر و کارت پایانی (`ادامه دارد...` یا «قسمت بعد: روزِ N»):

- کاراکترهای فرعی: (هر کدام کامل)
- مکان‌ها: (طرح ثابت: رنگ دیوار، در، وسایل)

## صدا
- راوی: (صدا، مدل، stability 0.5 / similarity 0.75، بی‌تگ برای مستند · `--tempo 1.08`)
- نقش‌ها و فیلترشان (`vo-fx`): اینترکام / دریچه / رادیو / تقلیدی
- موزیک: هر فصل یک حس، کراس‌فید روی شروع جمله. زیر نریشن حدود ‎-33 تا ‎-35 LUFS، و هر جمله ≥ ۱۰dB بالای بستر.
- موتیف تق‌تق: کجاها (جمله، تعداد، نوع: چوب، رادیو، کف) — هر ضربه = یک تکان تصویر.

## چک قبل از تحویل
- [ ] هیچ قابی بیشتر از ۹ ثانیه بی‌کات نیست، مگر آنکه پانچ داشته باشد.
- [ ] هیچ متنی روی صورت یا بدن کاراکتر نیست. زیرنویس روی زمینه‌ی خالی است.
- [ ] شب روی گوشی خوانا است (+۲۰٪).
- [ ] در عمودی، UI بالای y=236 نیست و هیچ متنی کوچک‌تر از ۲۸px نیست.
- [ ] روی جمله‌ای که کارت روز دارد، زیرنویس نیست.
- [ ] هر جمله دست‌کم ۱۰dB بالای بستر است (`margin.mjs`).
- [ ] کارت پایانی و فیدها درست‌اند و تعداد فریم کامل است (`finalize.mjs` چک می‌کند).
