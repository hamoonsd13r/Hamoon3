# Paper UI · «کاغذ و کارت» (ریلز روشن معرفی محصول: کاغذ، کارت سفید، گوشی تیره، ماژیک روی کلمه)
**وضعیت:** ✅ کد آماده در Remotion (DOM، بدون WebGL) · `src/styles/paper-ui/`
- `Style-PaperUI` · عمودی 1080×1920، ۳۰fps، ریلز ۲۵ ثانیه‌ای «اپ نوبت» (یک اپ ساختگی نوبت‌دهی سالن)
- `Style-PaperUI-Look` · همان فیلم، props `{ times }`
- دمو بی‌صداست (زمان نریشن تخمینی)؛ همه‌ی صفحه‌ها و داده‌ها با کد و ساختگی‌اند.

**مرجع:** دو ریلز تأییدشده‌ی معرفی اپ با طراحی روشن. کانتکت‌شیت: `styles/previews/paper-ui.jpg`.
**اسم‌های صدازدن:** «کاغذ و کارت»، «ریلز روشن»، «معرفی اپ روشن»، «طراحی روشن».

## کی بزنیمش
- **ریلز و شورت ۲۰ تا ۸۰ ثانیه با نریشن** برای معرفی اپ، سرویس یا محصول با قوس «مشکل ← راه‌حل ← نتیجه ← دعوت»؛ وقتی برند یا موضوع روشن و صمیمی است.
- **ورودی‌ها:** نریشن، صفحه‌ها و قابلیت‌های واقعی محصول (یا بازسازی‌شان با کد)، یک عدد نتیجه، جمله‌ی دعوت.
- **کی نه:**
  - حال‌وهوای تیره و سینمایی ← `noir-studio` یا `screen-showcase`.
  - خبر و بازار ← `market-file`.
  - تبلیغ با گوشی تنها و صفحه‌های عوض‌شونده با صدای تماس ← `phone-assistant`.

## ظاهر
- **رنگ** (`lib/theme.ts`): کاغذ گرم `bg #F3F0E9` با شبکه‌ی نقطه‌ای متحرک، جوهر `ink #111116`، کارت سفید، گوشی و کارت تیره. یک اکسنت `accent #FF8A3D` برای پرکردن (ماژیک، دکمه، روز روشن) و سایه‌ی تیره‌ترش `accentInk #C2560E` برای متن اکسنت روی کاغذ؛ قرمز فقط برای هشدار و مهر. برند خودت: `setPalette({ accent, accentHi, accentInk })`.
- **پس‌زمینه** (`Backdrop`): کاغذ، نقطه‌ها، دو هاله‌ی گرم سرگردان، هاله‌ی قرمز «هشدار» برای بخش مشکل، و یک کلمه‌ی غول‌پیکر کم‌رنگ برای هر بخش که آرام می‌لغزد.
- **قطعه‌ها** (`lib/kit.tsx`): `Card`، `Win` (پنجره‌ی روشن با تب)، `Phone` (گوشی تیره)، `Chip`، `Mark` (ماژیک راست به چپ پشت کلمه)، `Ico` (آیکون خطی)، `Stamp` (مهر)، `Toggle`، `Clock`، `Land` (عکس منظره با کد)، `Scene` و `In` (ورود و خروج).
- **حروف:** Vazirmatn (تیتر ۱۰۰ تا ۲۳۰ پیکسل، متن کارت ۲۴ تا ۳۴)، IBM Plex Mono برای کلمه‌ی پس‌زمینه.
- **زیرنویس:** قرص سفید، تکه‌های حداکثر ۵ کلمه، کلمه‌ی کلیدی با رنگ متن اکسنت.

## شروع سریع
1. متن: یک جمله در هر خط؛ قوس «مشکل ← راه‌حل ← نتیجه ← دعوت».
2. صدا و زمان کلمه‌ها: `tools/eleven-tts.mjs` ← `tools/eleven-align.mjs` ← `WORDS = normalizeWords(REAL)`.
3. کپی `demo/{Video.tsx,script.ts}` به `src/vNN/`؛ برای هر جمله یک صحنه (`SC`)، و لحظه‌ها در `K` روی کلمه‌ها.
4. محتوای صحنه‌ها را عوض کن: صفحه‌های محصول خودت داخل `Phone` و `Win`، عدد نتیجه، کلمه‌های پس‌زمینه (`GHOSTS`).
5. فریم‌ها: `node tools/look.mjs Style-PaperUI-Look "…" out/look --entry src/index.ts` ← رندر ← `tools/doc-mix.mjs` ← `tools/finalize.mjs`.

## API
- `Scene({ t, win: [a, b] })` · `In({ t, t0, dx?, dy?, s0?, style })` · `Card({ dark?, style })` · `Win({ x, y, w, h, title, tabs?, tab?, dark? })` · `Phone({ x, y, s?, rot? })` (صفحه ۴۲۰×۸۶۰).
- `Fa({ size, w?, color? })` · `Chip({ k, accent?, dark?, size? })` · `Mark({ t, t0 })` · `Ico({ k, s, c })` (code، chat، img، play، web، bolt، user، chart، cal، send، phone، bell، lock، check، card، scissors، clock، star).
- `Stamp({ k, text, color?, size?, rot? })` · `Toggle({ on })` · `Clock({ size, hour, minute })` (زاویه به درجه) · `Land({ w, h, pal })`.
- `Backdrop({ t, ghosts: [[time, "WORD"]], alarm? })` · `makeChunks(WORDS, /کلیدواژه|…/)` → `Subtitle({ t, chunks, from?, until? })`.

## دستورهای صحنه
- **قلاب:** کل سؤال از فریم ۰ روی صفحه، با آیکون‌های کار دورش؛ روی کلمه‌ی اصلی ماژیک رد می‌شود و آیکون مربوطش تیره و لرزان می‌شود.
- **مشکل:** پنجره‌ی روشن با فهرست واقعی (تماس‌های بی‌پاسخ، سفارش‌های لغوشده) که ردیف‌به‌ردیف می‌آیند، و یک کارت شبکه‌ای که خانه‌هایش خراب می‌شوند؛ مهر قرمز روی کلمه‌ی دردناک؛ هاله‌ی هشدار در پس‌زمینه.
- **راه‌حل در گوشی:** انتخاب قدم‌به‌قدم روی کلمه‌ها (خدمت ← ساعت ← تأیید)، فشار دکمه و مهر سبز «انجام شد».
- **قابلیت دوم:** صفحه‌ی قفل با اعلان واقعی، و کارت کنار گوشی با سوییچی که روشن می‌شود.
- **نتیجه:** یک عدد درشت که از عدد قبلی بالا می‌رود (هرگز از صفر)، با نمودار ستونی و چیپ اختلاف.
- **دعوت:** کلمه‌ی اصلی با ماژیک، کارت اپ، چیپ «لینک توی بیو» با فلش.

## صدا
- **راوی:** گرم و پرانرژی، بدون تگ؛ اسم محصول را آوایی بنویس و با STT چک کن.
- **موزیک:** پاپ یا الکترونیک روشن ۱۰۰ تا ۱۲۰BPM (MUSIC.md، «معرفی محصول»)؛ زیر نریشن حدود ‎-33 LUFS.
- **افکت:** پاپ روی کارت‌ها، تیک روی انتخاب، ضربه‌ی مهر، زنگ اعلان، ووش بین صحنه‌ها؛ حدود ‎-40 LUFS.

## درس‌ها
- **هیچ کارت UI خالی نماند:** هر کارت متن، عدد و تصویر واقعی دارد؛ بلوک خاکستری خالی پذیرفته نیست.
- **متن اکسنت روشن روی کاغذ کرم نه:** برای متن، سایه‌ی تیره‌ی اکسنت (`accentInk`).
- **فریم اول خالی نباشد:** قلاب از فریم ۰ کامل است.
- **چیپ‌ها و تیترها روی هم نیفتند:** هر صحنه جای ثابت برای تیتر، کارت و چیپ دارد؛ زیرنویس روی y=1530.
- **صفر فارسی (۰) شبیه نقطه است:** شمارنده از ۱ یا از یک عدد واقعی شروع شود.
