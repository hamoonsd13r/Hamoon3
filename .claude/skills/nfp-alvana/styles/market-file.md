# Market File · «پرونده‌ی خبر» (ریلز خبری و بازار، فوتیج‌محور با تیتر و دیتای متحرک)
**وضعیت:** ✅ کد آماده در Remotion (DOM، بدون WebGL) · `src/styles/market-file/`
- `Style-MarketFile` · عمودی 1080×1920، ۳۰fps، دموی ۴۸ ثانیه‌ای «چرا شکلات یهو این‌قدر گرون شد؟»
- `Style-MarketFile-Look` · همان فیلم، props `{ times }` → یک فریم برای هر زمان
- دمو بی‌صداست. زمان کلمه‌ها تخمینی است (`estimateWords`) و فوتیج ندارد: هر اسلات خالی یک جای‌خالیِ برچسب‌دار نشان می‌دهد که می‌گوید چه فوتیجی آنجا بنشیند.
- عددهای دمو **نمونه**اند و روی تصویر هم «داده‌ی نمونه» نوشته شده.

**مرجع:** سه ریلز خبری تأییدشده (بازار، سیاست، زیرساخت) که هر کدام بعد از یک منتقد تازه اصلاح شدند. کانتکت‌شیت: `styles/previews/market-file.jpg`.
**اسم‌های صدازدن:** «پرونده‌ی خبر»، «ریلز خبری»، «خبر بازار»، «چیپ روی کلمه»، «سیل رنگی».

## کی بزنیمش
- **ریلز اینستاگرام و شورت یوتیوب، ۴۰ تا ۹۰ ثانیه:** خبر روز، بازار و قیمت، اقتصاد، فناوری، رویداد جهانی. «چرا X گرون شد؟»، «آیا Y قطع می‌شه؟»، «این ادعا درسته؟».
- **ساختار:** یک سؤال داغ ← خبر ← عدد و منبع ← نقشه یا سهم ← دلیل‌ها ← سؤالِ اصلی (سیل رنگی) ← سناریو ← جمع‌بندی با تیک و ضربدر ← یک درخواست (کامنت).
- **ورودی‌ها:**
  - متن نریشن (TTS یا صدای خود کاربر + alignment).
  - برای هر عبارت یک کلیپ فوتیج آزاد (FOOTAGE.md؛ عکس هم می‌شود).
  - هر عدد با منبع و تاریخ.
  - اختیاری: آهنگ CC0 یا با مجوز (MUSIC.md).
- **کی نه:**
  - ویدیوی رو به دوربینِ خود کاربر ← talk-page (صفحه‌ی کاغذی) یا talk-cutout (کارت پشت سرش).
  - مستند بلند یوتیوب ← documentary یا painted-story.
  - بدون هیچ فوتیجی، اکسپلینر عددی و علمی ← hologram-hud.
  - تبلیغ محصول با UI ← launch-reel.
  - مونتاژ استعاری تند ← story-montage.

## ظاهر
- **رنگ** (`lib/theme.ts`، توکن‌ها):
  - `ink #0b0b0c` پس‌زمینه، `ink3` کارت‌ها، `cream #f2efe8` متن.
  - **فقط یک اکسنت:** `accent #f2762e` (نارنجی گرم) برای چیپ، حلقه، خط چارت، سیل رنگی.
  - `neg #ff5c5c` فقط برای قیمتِ ریزشی یا ادعای ردشده.
  - رنگ برند خودت: `setPalette({ accent: "#…" })` بالای فایل ویدیو. سبز نئون، فیروزه‌ای و بنفش نه.
- **حروف** (همه OFL): Vazirmatn 900 برای تیتر (فاصله‌ی حروف ‎-0.04em فقط روی لاتین)، Inter 700 برای عدد لاتین درشت، IBM Plex Mono برای برچسب‌های HUD و منبع (حروف بزرگ، فاصله‌ی ‎.24em).
- **چیدمان (۱۰۸۰×۱۹۲۰):**
  - بالا: گوشه‌های HUD با برچسب پرونده (`YOUR BRAND — FILE 01`)، کاشی برند در (۹۰، ۲۴۴) و نوار فصل کنارش.
  - تیتر هر صحنه از y=340، x=90، عرض ۹۰۰ (خودش کوچک می‌شود تا از قاب بیرون نزند).
  - کارت‌ها x بین ۷۰ و ۱۰۱۰، y بین ۷۰۰ و ۱۴۶۰. خط منبع زیر کارت (y حدود ۱۴۵۰ تا ۱۵۹۰).
  - هیچ متن مهمی پایین‌تر از ۱۶۰۰ (کپشن اینستاگرام) و راست‌تر از ۹۲۰ (دکمه‌ها)، جز تیتر کارت پایانی.
- **امضای حرکت:**
  - خط تیتر از تاری بالا می‌آید (۰.۳۸ث).
  - **چیپ**: روی همان لحظه‌ی گفتنِ کلمه از راست کشیده می‌شود، ‎-2.6° کج، با ضربه‌ی کوچک (×۱.۱۴).
  - روی ضربه‌ها لرزش دوربین ۰.۳۵ثانیه‌ای و گلیچ ۰.۲ثانیه‌ای.
  - **سیل رنگی:** کل قاب از وسط با اکسنت پر می‌شود و سؤال با جوهر روی آن می‌آید. فقط دو بار: سؤال اصلی و کارت پایانی.
  - فوتیج همیشه یک push آرام دارد (۲ تا ۴٪ در ثانیه)؛ دانه‌ی فیلم ۸٪ روی همه‌چیز.
- **ترنزیشن‌ها:** کات خشک فوتیج روی کلمه؛ بلوک‌های صحنه ۰.۲ ثانیه قبل از جمله‌ی بعد محو می‌شوند؛ سیل رنگی از وسط، کارت پایانی از پایین.

## شروع سریع
1. واقعیت‌ها: `src/styles/market-file/pipeline/direction-template.md` را پر کن (هر عدد با منبع).
2. متن: یک جمله در هر خط، `src/vNN/lines.txt` (۱۲ تا ۱۶ جمله).
3. صدا و زمان کلمه‌ها:
   ```bash
   node --env-file=.env tools/eleven-tts.mjs <voiceId> src/vNN/lines.txt public/vNN/voice.mp3 eleven_v4
   node --env-file=.env tools/eleven-align.mjs public/vNN/voice.mp3 src/vNN/lines.txt src/vNN/words-raw.json
   node tools/vo-tighten.mjs public/vNN/voice.mp3 src/vNN/words-raw.json public/vNN/voice-tight.wav
   ```
   ← `public/vNN/voice-tight.words.json` را به `src/vNN/words.json` کپی کن.
4. کپی دمو: `demo/{Video.tsx,script.ts,media.ts}` ← `src/vNN/`؛ ایمپورت‌ها را به `../styles/market-file/lib/…` برگردان. در `script.ts`: `LINES` خودت، `WORDS = normalizeWords(REAL)`، و `SC` با `at(خط, "کلمه")`.
5. فوتیج: `node tools/footage.mjs plan NN --text src/vNN/lines.txt` ← `find` ← `get`؛ هر کلیپ را در `MEDIA` اسم بده (یک کلیپ برای هر عبارت).
6. فریم‌ها: یک ترکیب `-Look` مثل `Compositions.tsx` بساز و `node tools/look.mjs V-NN-Look "0,3,8,…" out/look --entry src/index.ts`.
7. رندر بی‌صدا: `npx remotion render src/index.ts V-NN out/vNN-silent.mp4 --muted --crf=18`.
8. صدا و تحویل:
   ```bash
   node src/styles/market-file/pipeline/build-audio.mjs out/vNN-audio.json --stems --nomusic
   node tools/finalize.mjs out/vNN-silent.mp4 out/vNN-audio/mix.wav out/final vNN --nomusic out/vNN-audio/mix-nomusic.wav
   ```
   روال کامل با توضیح: `src/styles/market-file/pipeline/README.md`.

## API
- `Head({ t, t0, t1?, lines, size, y, x?, w?, lineAt?, on?, align? })` · خط‌ها آرایه‌ای از توکن‌اند: `"کلمه"` یا `{ w, chip?, slam?, pulse?, tail?, color?, size? }`. یک چیپ در هر تیتر.
- `ChipLabel({ k, size, style })` · برچسب چیپ‌دار کنار پین یا عدد.
- `Bed({ t, shots, media })` · `Shot = { a, b, slots, hint?, dim?, grade?, panel?, none?, focus?, push?, zoom?, trim?, rate? }`.
- `LineChart({ t, a, len, data, lo, hi, w, h, grid, gridLabel, ref? })` · روی کلمه‌ی زمان رسم می‌شود، چپ به راست.
- `HeroNumber({ t, a, hit, from, to, pre, post, y })` · عدد غول‌پیکر فارسی؛ از `from` می‌شمارد، هرگز از صفر.
- `DotGrid({ t, a, lit, litAt, x, y, cell })` · ۱۰۰ نقطه، `lit` تا یکی‌یکی روشن می‌شوند (راست به چپ).
- `NewsMap({ t, bbox, lit: [{ id, k }], pins: [{ ll, at, fa, mono, dx, dy }], labels, routes, zoom, origin })` · id = کد عددی ISO (`"364"` ایران، `"840"` آمریکا). داخل `MapBox({ y, h })`.
- `PhaseCard` + `PhaseBar({ segs: [x, w, از, تا][] })` · مراحل با نوار پیشرفت راست به چپ.
- `Curve({ k, w, h, ticks, yLabel, endLabel, f })` · منحنی سناریو (برچسب «سناریو، نه پیش‌بینی» کنارش).
- `Row({ t, at, mark, title, sub, kind: "check"|"cross"|"warn"|"dash", y, h })` داخل `Glass`.
- `Flood({ t, a, b?, mode: "circle"|"rise" })` · سیل رنگی؛ داخلش `Head` با `on="light"`.
- `makeShake(HITS)` · `Brow({ t, items })` · `Hud({ tl, tr })` · `BrandTile({ logo? })` · `BrandMark({ name?, logo? })`.
- `estimateWords(LINES)` · `normalizeWords(REAL)` · `makeTimeline(words)` → `{ at, end, S, E, VOICE_END }`.

## دستورهای صحنه
- **قلاب = کاور:** فریم ۰ کل سؤال را در سه اندازه دارد (۹۲ / ۱۵۰ / ۱۹۶) و چیپ روی کلمه‌ی داغ از فریم ۰ روشن است؛ وقتی گفته شد فقط یک پالس می‌خورد. زیرش یک خط mono و یک خط فارسیِ کم‌نور (موضوع · پرونده).
- **هر جمله یک تیتر:** خط اول با شروع جمله، خط دوم ۰.۰۵ ثانیه قبل از اولین کلمه‌اش. چیپ دقیقاً روی کلمه‌ی گفته‌شده، نه زودتر.
- **کارت دیتا:** ۰.۳۵ ثانیه قبل از کلمه‌اش وارد می‌شود؛ خط چارت روی کلمه‌ی زمان («توی یک سال») رسم می‌شود (۰.۹ث) و عدد بزرگ کارت **بعد از** تمام شدن خط ظاهر می‌شود. زیر کارت خط منبع.
- **عدد غول‌پیکر:** ۳۰۰px، روی کلمه‌ی عدد کامل می‌شود و کمی می‌پرد (×۱.۰۸). شمارش از عددی نزدیک شروع شود (۴۰ ← ۶۰)، نه از صفر: «۰» فارسی شبیه نقطه است و «۰٪» یعنی ادعا.
- **نقشه:** روی ink تمیز (بدون فوتیج)؛ کشور موضوع روی اسمِ خودش روشن می‌شود، پین با حلقه و اسم فارسی + mono؛ کشورهای کناری کم‌نور. نقشه تا اولین کلمه‌های جمله‌ی بعد می‌ماند (حداقل ۲.۵ ثانیه روی صفحه). مسیرها با «مسیرِ تقریبی».
- **سهم با نقطه:** «از هر ۱۰۰ تا، ۶۰ تاش…» → ۱۰۰ نقطه، ۶۰ تا یکی‌یکی روشن (۰.۰۱۲ث فاصله)، زیرش دو عدد با رنگ.
- **فهرست دلیل‌ها:** هر مورد وقتی گفته می‌شود یک ردیف می‌شود (با فوتیجِ همان مورد پشتش) و علامتش ۰.۳۵ ثانیه بعد مهر می‌خورد.
- **سؤالِ اصلی:** تیتر «حالا سؤالِ اصلی:» با چیپ؛ روی کلمه‌ی اول سؤال سیل رنگی از وسط باز می‌شود و سؤال با جوهر می‌آید؛ روی جمله‌ی بعد از بالا جمع می‌شود.
- **زمان یا مراحل:** سه کارت فاز (راست به چپ) و نوار زیرشان که با کلمه‌ها پر می‌شود؛ مرحله‌ی موضوع اکسنت می‌گیرد و آرام نفس می‌کشد.
- **آینده:** منحنی سناریو با برچسب «سناریو، نه پیش‌بینی». پیش‌بینی قیمت نه.
- **جمع‌بندی:** دو یا سه ردیف «… ؟ آره.» (تیک) / «… ؟ نه.» (ضربدر) / «… ؟ معلوم نیست.» (خط تیره)، هر کدام روی کلمه‌اش؛ زیرش یک جمله‌ی کم‌نور اگر چیزی قطعی نیست.
- **کارت پایانی:** سیل از پایین؛ جمع‌بندی در دو خط (چیپ روی کلمه‌ی دوم)، درخواست کامنت روی کلمه‌ی «کامنت»، برند، دکمه‌ی «دنبال کن». ۲.۹ ثانیه بعد از آخرین کلمه می‌ماند.

## صدا
- **راوی:** لحن خبری آرام، v4، stability 0.5، similarity 0.75، **بدون تگ احساس**. اسم‌های خاص را آوایی بنویس و با STT چک کن. فقط مکث‌های بین جمله‌ها (۰.۱۴ث) و بعد از ویرگول (۰.۱۸ث) کوتاه می‌شود (`tools/vo-tighten.mjs`).
- **موزیک:** CC0 یا با مجوز (MUSIC.md، سبک «خبری، تنش، الکترونیکِ تیره»). شروع آهنگ را طوری انتخاب کن که دراپ اول روی کلمه‌ی داغ قلاب بیفتد (`tools/beat-map.mjs`).
- **اتوماسیون (`pipeline/build-audio.mjs`):** low-pass زیر قلاب که روی دراپ باز می‌شود؛ ‎-6dB زیر هر جمله؛ ‎+3dB در مکث‌های ۰.۴ثانیه‌ای؛ ‎+3.5dB روی دراپ‌ها و سیل رنگی؛ قطع کامل زیر جمله‌ی «نکته‌ی مهم»؛ کم شدن کلمه‌به‌کلمه تا هر کلمه دست‌کم ۱۳.۵dB بالای موزیک باشد؛ محو بعد از آخرین کلمه.
- **افکت:** روی ضربه‌های تصویر (چیپ‌های مهم، سیل، مهر تیک)؛ هر فایل روی RMS ‎-20 تراز و بعد ‎-6dB. افکت هرگز روی کلمه نمی‌نشیند (باس افکت زیر صدا duck می‌شود).
- **سطح‌ها:** صدا ‎-20، موزیک ‎-33 تا ‎-35، افکت حدود ‎-40 LUFS؛ خروجی ‎-14 با پیک ‎-1.

## درس‌ها
- **فوتیج اول، موشن روی آن:** هر عبارت یک کلیپ تازه که دقیقاً همان جمله را نشان می‌دهد؛ هیچ کلیپی دو بار. صحنه‌ی فقط‌موشن فقط برای ضربه‌های برند (نقشه، سیل، توقف موزیک، کارت پایانی).
- **فوتیج نرم یا ۷۲۰p** را تمام‌قاب نکن: پنل ۱۶:۹ تیز روی کپیِ تار خودش (`panel: true`).
- **رنگ فوتیج:** قرمز و سبز و نارنجیِ تند فوتیج با `GRADE.mute` نزدیک پالت شود تا اکسنت تنها رنگ بماند.
- **دهانی که حرف می‌زند نه:** نمای آدمی که در فوتیج صحبت می‌کند زیر نریشن ما «دوبله‌ی تقلبی» دیده می‌شود؛ نمای ساکت یا از پشت بگذار.
- **ادعا ≠ واقعیت:** ادعای یک نفر با گیومه، نقش و «نقل به مضمون»؛ فقط همان چیزی را روی نقشه علامت بزن که رسماً گفته شده.
- **هر عدد منبع و تاریخ دارد** (خط `Src`). سناریو برچسب «سناریو، نه پیش‌بینی» می‌گیرد. پیش‌بینی قیمت هرگز.
- **چارت چپ به راست** است، حتی در فیلم فارسی.
- **هیچ دو متنی روی هم:** کارت قبلی کامل بیرون می‌رود، بعد بعدی می‌آید. نقطه یا ویرگولِ انتهای کلمه‌ی slam با خود کلمه ظاهر شود، نه زودتر.
- **قاب امن:** متن معنی‌دار ≥ ۲۴px؛ متن مهم x ≤ ۹۲۰ و y بین ۲۴۰ و ۱۶۰۰.
- **یک چیپ در هر تیتر.** دو چیپ در یک خط تأکید را می‌کشد.
- **سیل رنگی فقط دو بار** (سؤال اصلی و پایان)؛ بیشتر از آن ارزان می‌شود. لرزش فقط روی ضربه‌ها (حدود ۷ تا ۱۰ بار در دقیقه).
- **تیتر بلند** خودش کوچک می‌شود (اندازه‌گیری با خود فونت)؛ Chrome فاصله‌ی حروف را روی کلمه‌ی فارسی اعمال نمی‌کند، پس اندازه‌گیری هم نکند.
- **فوتیج زیر نقشه و چارت** فقط بافت باشد (`GRADE.mapbg`، تار و تیره).

## رندر و تحویل
- DOM خالص، **بدون GPU**؛ حدود ۰.۱ ثانیه برای هر فریم ۱۰۸۰×۱۹۲۰ (دموی ۴۸ ثانیه‌ای حدود ۲.۵ دقیقه). روی ابر و کامپیوتر ضعیف هم کار می‌کند؛ ریلز طولانی را با `tools/render-chunks.mjs` تکه‌تکه رندر کن.
- فریم‌ها قبل از رندر: `node tools/look.mjs Style-MarketFile-Look "0,2.8,7,13,20,30" out/look --entry src/index.ts`.
- رندر: `npx remotion render src/index.ts V-NN out/vNN-silent.mp4 --muted --crf=18`.
- تحویل: `node tools/finalize.mjs <silent.mp4> <mix.wav> <outDir> <name> --nomusic <mix-nomusic.wav>` (اصلی + گوشی + بی‌آهنگ).
- قبل از تحویل کانتکت‌شیت کل فیلم را ببین (هر ۰.۵ ثانیه یک فریم): فریم خالی، متن روی هم، کلیپ تکراری، عدد بی‌منبع.
