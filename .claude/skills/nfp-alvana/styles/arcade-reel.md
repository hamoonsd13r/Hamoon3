# Arcade Reel · «ریلز گیم‌پلی» (فوتیج تمام‌قاب بازی با کادرهای HUD که روی جزئیات می‌مانند)
**وضعیت:** ✅ کد آماده در Remotion (DOM و SVG، بدون WebGL) · `src/styles/arcade-reel/`
- `Style-ArcadeReel` · عمودی 1080×1920، ۳۰fps، ریلز ۲۵ ثانیه‌ای «بازی با یک پرامپت» (بی‌صدا، زمان کلمه‌ها تخمینی)
- `Style-ArcadeReel-Look` · همان فیلم، props `{ times }`
- **گیم‌پلی در کیت نیست:** دمو با دو صحنه‌ی بازیِ کدی (ریسر سینت‌ویو و شوتر فضایی) ساخته شده؛ در ویدیوی خودت `Foot` فوتیج بازی را پخش می‌کند و جای خالی‌اش `Slot` است.

**مرجع:** ریلز تأییدشده‌ی «بازی‌هایی که با یک پرامپت ساخته شدند» (گیم‌پلی تمام‌قاب روی ضرب، کادر روی HUD بازی). کانتکت‌شیت: `styles/previews/arcade-reel.jpg`.
**اسم‌های صدازدن:** «ریلز گیم‌پلی»، «کادر HUD»، «آرکید»، «بازی با پرامپت».

## کی بزنیمش
- **ریلز و شورت ۱۵ تا ۶۰ ثانیه درباره‌ی بازی یا هر چیز پرحرکتی که فوتیجش داری:** «این بازی رو با هوش مصنوعی ساختم»، معرفی بازی، بخش‌های یک بازی (ماشین، صدا، دشمن)، پشت‌صحنه‌ی کد.
- **ورودی‌ها:** نریشن، کلیپ‌های گیم‌پلی (ضبط صفحه‌ی خودت)، جزئیاتی که باید نشان داده شوند (مختصات روی فیلم)، عددها (سرعت، خط کد)، کلمه‌ی کامنت.
- **کی نه:**
  - اپ چت و دستور اسلش ← `inside-app`.
  - خبر و بازار ← `market-file`.

## ظاهر
- **رنگ** (`lib/theme.ts`): مشکی `#060608` و یک اکسنت `accent #FF5A36` (کادرها، کلمه‌ی گفته‌شده، عقربه، قفل). برند خودت: `setPalette({ accent, accentHot, accentHi, accent300, onAccent })`.
- **فوتیج** (`Foot`): تمام‌قاب یا عرض‌کامل با کپی تار پشتش، push آرام، ضربه روی ضرب و لرزش روی ضربه‌ها (`camera`)، ورود «punch» یا «whip» (`enterFx`).
- **کادر روی جزئیات** (`Callout` + `boxOf`): مستطیل اکسنت که خودش کشیده می‌شود و یک برچسب فارسی و mono؛ با `boxOf` روی یک مستطیل از خود فیلم قفل می‌ماند حتی وقتی تصویر push می‌شود.
- **ویجت‌ها:** سرعت‌سنج (`Speedo`)، تراشه‌ی صدا با میله‌هایی که روی ضربه‌ها می‌پرند (`SoundChip`)، دیوار کد (`CodeWall`)، کارت ابسیدین (`CardBox`)، قفل (`Lock`)، قرص (`Pill`).
- **زیرنویس** (`Caps`): یک عبارت در هر لحظه، کلمه‌ی گفته‌شده اکسنت؛ بالای ماشین و سفینه (y≈۱۳۲۰).
- **حروف** (همه OFL): Vazirmatn، IBM Plex Mono، Inter.

## شروع سریع
1. گیم‌پلی را ضبط کن (۷۲۰p یا بیشتر)؛ برای هر عبارت نریشن یک تکه.
2. صدا: `tools/eleven-tts.mjs` ← `tools/eleven-align.mjs` ← `WORDS = normalizeWords(REAL)`؛ عبارت‌های زیرنویس در `CHUNKS`.
3. کپی `demo/{Video.tsx,script.ts}` به `src/vNN/`؛ به‌جای `RacerPlate`/`ShooterPlate` بنویس `<Foot clip={{ src, w, h, len }} t={t} t0={…} len={…} fr={{ focus: [x, y], push: 0.03 }} />` و کادرها را با `boxOf(clip, frame, t, t0, [sx, sy, sw, sh])` روی جزئیات بگذار.
4. فریم‌ها: `node tools/look.mjs Style-ArcadeReel-Look "…" out/look --entry src/index.ts` ← رندر ← میکس (صدای خود بازی + موزیک) ← `tools/finalize.mjs`.

## API
- `Foot({ clip: { src, w, h, len }, t, t0, len, ss, fr: { focus, zoom, push, fit: "cover" | "width" }, filter, dim })` · `xf(clip, frame, t, t0)` · `boxOf(clip, frame, t, t0, [sx, sy, sw, sh])` → `{ x, y, w, h }` روی صفحه.
- `camera(t, ضربه‌ها, [[از، تا]] پرانرژی, ضرب‌ها)` → `{ x, y, s }` · `enterFx("punch" | "whip", ثانیه از ورود)`.
- `Callout({ x, y, w, h, k, label, mono, below })` · `Speedo({ x, y, size, v, k })` (v از ۰ تا ۱ = ۰ تا ۱۴۰) · `SoundChip({ t, k, hits, label })` · `CodeWall({ t, t0, k, code })` · `CardBox({ x, y, w, h, k, lit })` · `Lock({ size, open, glow })` · `Pill({ k, fa, mono })` · `Caps({ t, y, words, chunks, hide })`.

## دستورهای صحنه
- **قلاب:** گیم‌پلی از فریم ۰ با تیتر دوخطی (کلمه‌ی کلیدی اکسنت که روی گفتنش ضربه می‌خورد).
- **اسم بردن از چیزها:** هر کلمه = یک کادر روی همان چیز در فیلم؛ کادر بعدی وقتی قبلی هنوز هست، نه بیشتر از دو کادر.
- **عدد زنده:** سرعت‌سنج با کلمه‌اش بالا می‌رود و روی «ترمز/تصادف» پایین می‌آید؛ لرزش دوربین و لبه‌ی قرمز به‌جای فلاش سفید.
- **صدا:** تراشه‌ی صدا با میله‌هایی که روی صداهای خود بازی می‌پرند.
- **بازی دوم:** ورود ویپ؛ کادر روی دشمن‌ها، انفجارها روی کلمه‌ی «حمله».
- **پشت صحنه:** دیوار کد روی فوتیج تار و تیره، شمارنده‌ی خط کد (از عدد واقعی، نه صفر).
- **پایان:** کارت قفل که روی «کامنت» باز می‌شود.

## صدا
- **صدای خود بازی** (موتور، ترمز، شلیک) زیر نریشن، روی تصویر خودش؛ ضربه‌ها روی کلمه‌ها.
- **موزیک:** پرانرژی ۱۲۰ تا ۱۳۰BPM (MUSIC.md، «پرانرژی»)؛ ورود صحنه‌ها روی ضرب.
- **افکت:** ووش ویپ، تیک کادرها، کلیک قفل؛ حدود ‎-40 LUFS.

## درس‌ها
- **کادر باید روی همان چیزی بماند که گفته می‌شود:** با `boxOf` از مختصات خود فیلم حساب کن، نه عدد ثابت روی صفحه.
- **push زیاد (بیشتر از ۵٪) کادر را از HUD جدا می‌کند.**
- **زیرنویس روی قهرمان (ماشین، سفینه، صورت) نیفتد:** ارتفاع زیرنویس را برای هر سبک تنظیم کن.
- **فلاش سفید نه:** ضربه = لرزش دوربین + لبه‌ی رنگی.
- **فوتیج بازی دیگران** فقط اگر حق استفاده داری (ضبط خودت از بازی خودت بهترین است).

## رندر و تحویل
- DOM و SVG، **بدون GPU**؛ حدود ۰.۱ ثانیه برای هر فریم (با فوتیج کمی بیشتر).
- فریم‌ها: `node tools/look.mjs Style-ArcadeReel-Look "0,3,6,9,14,20" out/look --entry src/index.ts`.
- تحویل: `node tools/finalize.mjs <silent.mp4> <mix.wav> <outDir> <name>`.
